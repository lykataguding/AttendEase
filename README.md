AttendEase

A Mobile-Friendly Attendance Management Application

 About the Project

AttendEase is a simple attendance management application designed to help teachers organize their classes, manage student information, record attendance, and view attendance records.

 Features

- User Registration and Login – Allows users to create an account and log in securely.
- Dashboard– Displays attendance information and summaries.
- Class Management – Allows teachers to manage their classes and sections.
- Student Management – Allows teachers to add and manage student records.
- Attendance Recording – Allows teachers to record student attendance.
- Attendance History – Allows teachers to view previous attendance records.
- Firebase Integration – Uses Firebase Authentication and Cloud Firestore to manage user accounts and store application data.

 Technologies Used

- HTML
- CSS
- JavaScript
- Firebase Authentication
- Cloud Firestore

 How to Install and Run

1. Download or clone this repository from GitHub.
2. Extract the downloaded ZIP file if you downloaded it as a ZIP.
3. Open the project folder in Visual Studio Code.
4. Make sure the Firebase configuration in `firebase.js` is properly set.
5. Install the Live Server extension in Visual Studio Code if you haven't installed it yet.
6. Right-click `index.html` and select **Open with Live Server**.
7. The application will open in your browser.
